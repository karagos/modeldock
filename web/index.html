Memory (RAM) for the "fits" badge

The green/orange/red dots compare each model file to this amount of memory. Leave on Auto for this Mac, or pick a size to plan for a different machine.

What the colors mean (in a model's file list)

Green: runs comfortably. The file is at most ~60% of the memory chosen above, leaving room for long conversations and your other apps.

Orange: tight. 60–85% of memory: it will load, but expect it to be slow; close other heavy apps first.

Red: won't run. Bigger than ~85% of memory. Realistically this machine can't hold it. Pick a smaller quantization (e.g. Q4 instead of Q8).

Highlighted row: your preferred quantization. Files matching the quantization chosen above get an orange border so the recommended pick jumps out.

The dots always follow the Memory setting above. Set it to a different size to preview what a future Mac could run. On Apple Silicon, memory is shared between processor and graphics, so file size versus memory honestly predicts how a model runs.
