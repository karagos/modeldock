What the colors mean (in a model's file list)

Green: runs comfortably. The file is at most ~60% of the memory chosen above, leaving room for long conversations and your other apps.

Orange: tight. 60–85% of memory: it will load, but expect it to be slow; close other heavy apps first.

Red: won't run. Bigger than ~85% of memory. Realistically this machine can't hold it. Pick a smaller quantization (e.g. Q4 instead of Q8).

Highlighted row: your preferred quantization. Files matching the quantization chosen above get an orange border so the recommended pick jumps out.

The dots always follow the Memory setting above. Set it to a different size to preview what a future Mac could run. On Apple Silicon, memory is shared between processor and graphics, so file size versus memory honestly predicts how a model runs.

▣ Welcome to ModelDock

The home port for your local AI. Three steps to your first model: pick a destination folder in Settings (your external SSD), find a model in Search, press Download. Everything below makes you faster.

Search & discovery

  • Start page: with an empty search you see your Watchlist, Trending now, Fresh lab releases, and Most downloaded. The ⌂ Home button brings it back anytime.
  • ☆ Star any model to watch it without downloading. Ideal for models your next Mac could run.
  • Search looks inside model cards, not just names: try an interest like "culinary" or "chess". Extra finds carry a readme match pill.
  • ≈ Broaden fans your word out to siblings (cooking also tries culinary, recipe, chef). Each extra result says which word found it.
  • Most downloaded ▾ hides a Period picker: last 30 days, all time, or only models released in the last 6 or 12 months.
  • Combine filters freely: Domain + ≤4B SLM finds small specialist models; capabilities like Thinking + MoE stack.
  • Quantizers row: Unsloth, bartowski, mradermacher, LM Studio and friends often ship the best ready-to-run versions.
  • Recent and saved searches live under the search bar. ☆ Save names the current search for one-click re-runs.

Inside a model

  • Colored dots answer "will it fit my memory?": green comfortable, orange tight, red won't run. Set the memory size in Settings to plan for a future Mac.
  • Your preferred quantization glows; versions you already own show In library ✓.
  • License pill: plain-language verdicts like "Commercial use OK".
  • Lineage: jump to the base model, or list every fine-tune and quantization of it.
  • No GGUF files? A "Full repository" download still gets you the model.

Downloads that cannot break

  • Refreshing or closing the browser never stops a download; it runs in the app itself.
  • Power cut, crash, unplugged drive, lost connection: progress is kept and resumes from the exact byte, automatically after a crash.
  • Every byte is checksummed while it streams. A file only gets its real name after verification, so a half file can never pose as a model.

Library & settings

  • Verify re-proves a model's integrity anytime against recorded checksums.
  • Copy as Markdown turns your collection into a paste-ready table for docs and posts.
  • Delete always goes to the Trash, never permanent. The Library reads the real drive, so Finder changes show instantly.
  • Point LM Studio at Models/llm and ComfyUI at Models/comfyui: downloads appear there automatically.
  • A free Hugging Face token in Settings unlocks gated models (Llama, Gemma, Flux dev).
